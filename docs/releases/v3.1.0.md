# CodeRecoder 3.1.0

修复开启保护时正常备份被判为无效的问题，补齐 Serena 安装及 Linux 安装包。

- 中文、大小写和 Unicode 路径使用稳定排序；已有备份保持原始内容和哈希并可继续读取、校验和恢复。
- 备份遇到并发编辑时最多重试两次，不发布未通过校验的数据。
- 新增 Serena 下载按钮、固定上游源码安装器和可选 .NET 10 安装；修复多语言配置在后台中止的问题。
- `.deb` 注册桌面图标，内置 CodeRecoder MCP 运行时，提供 `coderecoder-mcp` 与 `coderecoder-install-serena`。
- 修复 GNOME 图标关联、Electron 代理下载与 MCP 服务名称不一致。

下载 `.deb` 和 `SHA256SUMS` 到同一目录后运行：

```bash
sha256sum -c SHA256SUMS
sudo apt install ./CodeRecoder-3.1.0-amd64.deb
```

Codex 可使用 `codex mcp add coderecoder -- /usr/bin/coderecoder-mcp`。Serena 单独安装：`coderecoder-install-serena`；C# 工程增加 `--with-dotnet`。语言服务首次初始化需要网络和对应语言依赖。

如果曾安装源码版快捷方式，请备份移走用户级 `~/.local/share/applications/coderecoder.desktop`，再启动系统应用菜单中的 CodeRecoder。
